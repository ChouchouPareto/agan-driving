# UI视觉与页面设计基线 v0.1（已废止）

> 本文件中的“安心驾校＋轻松校长”方向已被创作者否决。第一版UI改以 Refero 中 `site_id=74` 的 Loom 页面样例为主参考，执行规范见《Loom参考UI统一设计系统 v1.0》。本文件仅保留过程记录，不得用于后续设计或生成页面。

## 1. 推荐结论

推荐采用“**安心驾校＋轻松校长**”方向：整体专业、清晰、可信，用少量幽默文案和校长形象增加亲近感；不做儿童教育风、游戏风或传统政务后台风。

```text
专业可信的界面骨架
+ 温和清爽的青绿色
+ 少量琥珀色行动按钮
+ 轻松但克制的校长IP
+ 大字号、短答案、强层级
```

这套方向用于成年驾考学员，核心感受排序为：

> 看得懂 > 相信它 > 愿意继续用 > 觉得有趣。

## 2. 三个视觉方向

### A. 安心驾校＋轻松校长（推荐）

- 气质：可信、亲切、轻松、成年化；
- 主色：深青绿；
- 强调色：琥珀黄；
- 页面：浅色背景、白色卡片、适度圆角；
- 校长IP：小面积出现在欢迎、等待和处理结果状态；
- 适合：学员高频使用、驾校品牌交付、后续商业化。

### B. 活力学习

- 气质：年轻、明亮、激励感强；
- 主色：亮蓝；
- 强调色：橙色；
- 页面：大色块、进度感和学习激励更明显；
- 风险：容易接近通用刷题App，弱化驾校服务感。

### C. 极简工具

- 气质：严谨、高效、工具化；
- 主色：藏青；
- 强调色：单一绿色；
- 页面：大量留白、少装饰、弱IP；
- 风险：可信但缺少温度，“不懂就问校长”的记忆点不突出。

## 3. 推荐色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 品牌主色 | `#0F766E` | 主按钮、激活导航、关键标题 |
| 主色亮阶 | `#14B8A6` | 进度、轻提示、插图辅助 |
| 行动强调 | `#D97706` | 拍照提问、提醒、重要行动 |
| 页面背景 | `#F4F8F7` | 全局浅色背景 |
| 卡片背景 | `#FFFFFF` | 回答卡、历史卡、面板 |
| 主文字 | `#172B2A` | 标题和正文 |
| 次文字 | `#526663` | 辅助说明和时间 |
| 边框 | `#D7E4E1` | 卡片、输入框、分割线 |
| 成功 | `#15803D` | 看懂、已完成、已改善 |
| 警告 | `#B45309` | 等待、OCR需校正、提醒 |
| 错误 | `#DC2626` | P0、失败和明确错误 |

要求：正文与背景对比度不低于4.5:1；状态不能只靠颜色表达，必须同时有文字或图标。

## 4. 字体与文字层级

中文统一使用：

```text
Noto Sans SC
回退：PingFang SC / Microsoft YaHei / system-ui / sans-serif
```

| 层级 | 移动端字号 | 字重 | 用途 |
|---|---:|---:|---|
| 页面标题 | 24px | 700 | 当前页面核心标题 |
| 模块标题 | 18px | 600 | 卡片或功能分组 |
| 正文 | 16px | 400 | 问题、回答和说明 |
| 强调答案 | 20px | 700 | 直接答案 |
| 辅助文字 | 14px | 400 | 来源、时间、提示 |
| 最小标签 | 12px | 500 | 状态标签，不用于长正文 |

正文行高1.6；一行建议不超过22个中文字符；默认回答先短后长。

## 5. 形状、间距与层级

- 基础间距单位：4px；常用间距为8、12、16、24、32px；
- 页面左右安全边距：移动端16px；
- 卡片圆角：16px；按钮与输入框圆角：12px；标签圆角：8px；
- 卡片以1px浅边框为主，阴影只用于浮层和关键回答卡；
- 禁止大量玻璃拟态、厚重阴影、3D黏土效果和高饱和渐变；
- 触控区域最小44×44px，相邻操作至少间隔8px；
- 所有加载、上传、提交和状态切换必须有即时反馈。

## 6. 校长IP使用规则

推荐使用“轻量校长头像/半身插图”，但不做真人照片，也不做幼儿卡通。

出现位置：

- 首页欢迎语；
- “不懂就问校长”入口；
- 校长在摸鱼、校长处理中、校长已回复等状态；
- 空状态和轻提示。

不出现位置：

- 法规原文和标准答案正文旁；
- P0错误警告；
- 数据隐私、删除确认等严肃操作；
- 驾校管理看板的密集数据区。

原则：校长IP负责降低距离感，题库来源、法规依据和审核状态负责建立可信度。

## 7. 学员端整体布局

### 移动端优先

- 基准宽度：375px；兼容320—430px；
- 顶部：驾校品牌＋当前页面标题＋通知；
- 主内容：单列卡片；
- 底部主导航控制在4项：`问校长 / 学习记录 / 提醒 / 我的`；
- 对话页底部使用安全区内固定输入栏；
- 拍照和文字输入并列，但拍照为更醒目的辅助主行动。

### 桌面端Web

- 学员端内容最大宽度480px，居中模拟移动端使用体验；
- 背景可以展示轻量驾校品牌图形，不扩展成复杂三栏聊天系统；
- 教练/运营后台采用1280—1440px桌面布局，侧边导航＋内容区。

## 8. 核心页面骨架

### 8.1 首页

```text
驾校品牌 / 通知

校长欢迎卡
“今天哪里没看懂？”

[输入问题________________]
[拍照问]     [文字问]

未读：校长已回复
今日学习提醒
最近问过

底部导航
```

首页第一屏必须直接完成提问，不能先展示营销Banner或功能宫格。

### 8.2 对话页

```text
返回 / 科目一助教 / 依据说明

学员问题

直接答案卡
一句话解释
为什么这样选（可展开）
易错提醒
法规依据（折叠）

[我看懂了] [还是不懂]
[答案有问题] [再练类似题]

固定输入栏 / 拍照按钮
```

直接答案必须在首屏内出现；法规依据默认折叠；“答案有问题”不能使用容易误触的危险红色大按钮。

### 8.3 OCR校正页

```text
题目图片预览
识别出的题干
识别出的选项A/B/C/D

[有错误，点击修改]
[确认并提问]
```

低置信度内容使用黄色标记，不能让学员面对整段不可编辑OCR文本。

### 8.4 不懂就问校长

```text
校长状态插图
当前趣味状态
预计处理时间

原问题摘要
处理时间线
校长回复内容

[我知道了] [继续追问]
```

状态文案：

```text
提交给校长
→ 校长在摸鱼
→ 校长处理中
→ 校长已回复
→ 校长说好了
```

“校长在摸鱼”下必须同时显示正式解释：`问题已进入队列，预计在工作时间2小时内处理`，避免用户误以为服务无人负责。

### 8.5 学习记录

- 顶部显示薄弱知识点，不先显示累计提问等虚荣数据；
- 按“薄弱 / 疑似薄弱 / 已改善”分组；
- 每个知识点可以查看关联问题和练习相似题；
- 空状态引导发起第一次提问。

### 8.6 驾校效果看板

- 第一层：活跃学员、提问量、问题解决率、AI独立解决率；
- 第二层：质量趋势和“不懂就问校长”介入情况；
- 第三层：高频问题和薄弱知识点；
- P0和待处理工单固定在顶部告警区；
- 不展示学员公开排行榜。

## 9. 交互与动效

- 普通按钮反馈：150—200ms；
- 卡片切换/展开：200—250ms；
- 页面进入只使用轻微淡入，不使用大幅弹跳；
- “校长在摸鱼”可以有克制的小幅呼吸或钟摆动画；
- `prefers-reduced-motion`下关闭非必要动画；
- 骨架屏必须预留最终内容高度，避免页面跳动；
- 浏览器返回键保持可预测，不能丢失当前对话。

## 10. 明确禁止

- 儿童卡通、Comic字体、黏土3D和玩具化按钮；
- 大面积交通警示黄黑配色；
- 首页先展示驾校营销广告；
- 一个页面同时出现多个抢眼主按钮；
- 用Emoji代替正式功能图标；
- AI回答使用大段灰字或小于16px正文；
- 把模型置信度百分比直接展示给学员；
- 用红色表达普通等待或一般薄弱点；
- 后台和学员端使用完全不同的品牌色体系。

## 11. 后续视觉交付顺序

设计基线确认后，一次性完成：

1. 首页；
2. 文字问答页；
3. 拍照与OCR校正页；
4. “不懂就问校长”五个状态；
5. 学习记录与提醒；
6. 教练审核页；
7. 驾校效果看板；
8. 移动端、平板和桌面响应式标注；
9. 组件库与设计Token。

不先做全部高保真页面。先确认首页、回答页和“不懂就问校长”三张关键视觉稿，再批量延展其余页面，可以最大程度减少返工。
