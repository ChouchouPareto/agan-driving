## 1. 结论

当前版本已发布为 **V2.0 Beta 邀请测试版**。前后端运行于火山引擎 veFaaS，公网 HTTPS 入口、邀请码登录、学员数据隔离、AI 对话、知识库检索及题目回答主链路均已完成线上冒烟验证。

SQLite 数据库已接入私有 TOS Bucket，启动时可从 `backups/app.db` 恢复，运行期写操作后自动备份。当前仍不建议宣称为正式生产版：题库是研究联调预览版，OCR 文件尚未完成长期对象存储闭环，且尚未完成正式压力测试。

| 层级 | 当前实现 | 上线安排 |

## 3. 已完成的上线适配

- 创建发布分支，与原开发分支隔离，便于回退。
- veFaaS CLI `0.3.1`，满足手册 `>=0.2.7` 要求。
- 账号已通过 SSO 登录，已发现可用 Serverless 网关 `qweroo`。
- 后端识别为 Python 3.12 应用，端口 `8000`；发布时将显式使用无 `--reload` 的 uvicorn 命令。
- 前端识别为 Next.js 应用，端口 `3000`，已开启 `standalone` 输出。
- 前后端已分别增加 veFaaS 忽略规则，排除 `.env`、测试产物、开发数据库和私有图片，防止密钥与开发数据被打包。
- 创建私有 TOS Bucket `agan-driving-beta-2131129061`，启用版本控制，并以最小权限 IAM 用户完成读写删除探测。
- 后端采用轻量 TOS 客户端，避免原生 SDK 依赖影响 Serverless 构建；已上传脱敏生产数据库到 `backups/app.db`。
- 新增后端健康检查端点 `/api/v1/health`，可验证服务、数据库与真实模型连接状态。
- 普通对话输入上限从 2000 字降至 300 字，前端 `maxLength` 和后端 Pydantic 校验一致，降低 Token 浪费与恶意输入攻击面。

## 5. 安全分析

### 已有措施

- 模型 Key 不进前端，前端通过同源 Route Handler 访问后端。
- 学员会话使用 HttpOnly、SameSite Cookie，线上默认 Secure。
- 数据查询按 `student_id`/`school_id` 隔离，校长接口使用独立会话。
- 已有提示词注入、敏感信息、身份证/银行卡/验证码拦截。
- 后端异常统一返回安全文案，不将堆栈透出给用户。
- 聊天文字最大 300 字；图片最大 10 MB，并校验像素和文件类型。

### 上线后必须补齐

- API 级限流（账号/IP/路由三层）和模型并发上限。
- 生产邀请码不得继续使用文档中的测试码。
- 结构化日志需统一记录 `request_id`、耗时、路由、状态码，不记录学员原文和密钥。
- 正式压力测应使用专用测试邀请码和隔离数据库，不能直接污染学员数据。

## 6. 数据与文件风险

| 风险 | Beta 处置 | 正式版要求 |
| --- | --- | --- |
| SQLite 数据丢失 | 已实现 TOS 启动恢复与写后备份，并开启 Bucket 版本控制 | 放量后迁移 PostgreSQL，并增加定时恢复演练 |
| OCR 图片丢失 | Beta 可暂停公网 OCR 上传或标明临时存储 | 图片改存私有 TOS Bucket，通过有效期链接读取 |
| Chroma 索引丢失 | 使用可重建的原始题库，索引不作为唯一真源 | 发布时自动重建，或将持久化索引放到可恢复存储 |

## 7. 云资源与费用说明

当前账号已有 Serverless 网关 `qweroo`，本次直接复用，没有重复购买网关实例。阿甘学车使用独立函数和独立 APIG Service，不覆盖账号中已有的 `grokking-nao-api / grokking-nao-web` 产品。

火山引擎官方资料显示，veFaaS 默认为按量后付费；国内地域调用费为 0.01 元/万次，CPU 弹性实例按 vCPU 与内存执行时长计费，公网出流量为 0.8 元/GiB。本次 Beta 首发建议使用弹性实例、最小实例数 0，先不创建长期占用的预留实例；实际费用以控制台账单为准。

## 9. 发布与回滚方案

1. 部署后端应用，配置生产环境变量。
2. 访问 `/api/v1/health`，要求 HTTP 200 且 `status=ok`。
3. 部署前端应用，将 `BACKEND_API_URL` 指向后端。
4. 验证错码拒绝、正码登录、对话、刷题、错题、校长工单、手机布局。
5. 对比 A/B 两个学员会话，确认数据不串号。
6. 记录前后端 Application ID、Function ID、发布记录和公网域名。
7. 上线异常时回滚到上一个已验收 Revision；不删除共享网关。

## 10. Beta 验收标准

- 公网 HTTPS 首页可打开，手机无横向滚动。
- 邀请码登录成功，Cookie 不可被前端 JavaScript 读取。
- 普通对话、学车压力疏导、政策/流程问答和科目一理论题可完成一轮。
- 输入超过 300 字时，前端阻止继续输入，绕过前端的 API 请求返回 422。
- 刷题、模拟考、错题和收藏可用；否定句“不想刷题”不自动跳转。
- 开放问题无可靠来源时不猜，以轻量补充提示代替 404 式错误卡。
- 服务错误不向用户展示 Python/Next.js 堆栈。
