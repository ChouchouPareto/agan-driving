# 阿甘学车 V2.0 Beta 上线技术分析报告

> 报告版本：V2.0 Beta
>
> 日期：2026-08-28
>
> 发布分支：`codex/v2.0-beta-release-20260828`
>
> 依据：《AI Agent 产品上线部署手册 V1.1》、V2.0 PRD、当前代码与测试结果

## 1. 结论

当前版本已达到“公网 Beta 测试”的功能完整度，前后端可分别部署到火山引擎 veFaaS，邀请码登录、学员数据隔离、AI 对话、知识库检索、刷题、错题、OCR 和校长工单等主链路已存在。

但不建议将当前状态直接标记为“正式生产版”，原因是 SQLite、OCR 图片和向量索引仍依赖本地磁盘，暂无对象存储备份与启动恢复。本次发布定位为 **V2.0 Beta 邀请测试版**：先用小范围学员验证真实体验，完成数据可恢复改造后再升级为正式版。

## 2. 当前技术架构

| 层级 | 当前实现 | 上线安排 |
| --- | --- | --- |
| 学员端 | Next.js 16、React 19、移动端优先 | 独立 veFaaS Web 应用 |
| 业务 API | FastAPI、Python 3.12、SQLAlchemy | 独立 veFaaS API 应用 |
| AI 模型 | 通义/DashScope 兼容接口 | Key 仅放 veFaaS Secret/环境变量 |
| PE/Skill | 意图识别、陪伴对话、理论答疑、安全防护、刷题路由 | 后端执行，前端不持有模型 Key |
| RAG | 标准题库、权威咨询资料、Chroma 适配 | Beta 阶段随应用包发布，向量持久化待完成 |
| 业务数据 | SQLite | Beta 临时使用 `/tmp/data/app.db`；正式版必须备份/恢复或迁移 PostgreSQL |
| 图片 | 后端私有本地目录 | 正式版必须迁移 TOS，不能依赖函数本地磁盘 |
| 登录 | 学员邀请码、校长邀请码、HttpOnly Cookie | 保留，全程 HTTPS，生产 Cookie 强制 Secure |

## 3. 已完成的上线适配

- 创建发布分支，与原开发分支隔离，便于回退。
- veFaaS CLI `0.3.1`，满足手册 `>=0.2.7` 要求。
- 账号已通过 SSO 登录，已发现可用 Serverless 网关 `qweroo`。
- 后端识别为 Python 3.12 应用，端口 `8000`；发布时将显式使用无 `--reload` 的 uvicorn 命令。
- 前端识别为 Next.js 应用，端口 `3000`，已开启 `standalone` 输出。
- 前后端已分别增加 `.vefaasignore`，排除 `.env`、依赖目录、测试产物、数据库和私有图片，防止密钥与开发数据被打包。
- 新增后端健康检查端点 `/api/v1/health`，可验证服务、数据库与真实模型连接状态。
- 普通对话输入上限从 2000 字降至 300 字，前端 `maxLength` 和后端 Pydantic 校验一致，降低 Token 浪费与恶意输入攻击面。

## 5. 安全分析

### 已有措施

- 模型 Key 不进前端，前端通过同源 Route Handler 访问后端。
- 学员会话使用 HttpOnly、SameSite Cookie，线上默认 Secure。
- 数据查询按 `student_id`/`school_id` 隔离，校长接口使用独立会话。
- 已有提示词注入、敏感信息、身份证/银行卡/验证码拦截。
- 后端异常统一返回安全文案，不将堆栈透出给用户。
- 聊天文字最大 300 字；图片最大 10 MB，并校验像素和文件类型。

### 上线后必须补齐

- API 级限流（账号/IP/路由三层）和模型并发上限。
- 生产邀请码不得继续使用文档中的测试码。
- 结构化日志需统一记录 `request_id`、耗时、路由、状态码，不记录学员原文和密钥。
- 正式压力测应使用专用测试邀请码和隔离数据库，不能直接污染学员数据。

## 6. 数据与文件风险

| 风险 | Beta 处置 | 正式版要求 |
| --- | --- | --- |
| SQLite 数据丢失 | 仅小范围邀请测试，不宣称长期留存 | 定期加密备份到 TOS，启动时自动恢复；或迁移 PostgreSQL |
| OCR 图片丢失 | Beta 可暂停公网 OCR 上传或标明临时存储 | 图片改存私有 TOS Bucket，通过有效期链接读取 |
| Chroma 索引丢失 | 使用可重建的原始题库，索引不作为唯一真源 | 发布时自动重建，或将持久化索引放到可恢复存储 |

## 7. 云资源与费用说明

当前账号已有 Serverless 网关，无需本次新建网关。需要新建两个 veFaaS 应用：`agan-driving-api` 与 `agan-driving-web`。

火山引擎官方资料显示，veFaaS 默认为按量后付费；国内地域调用费为 0.01 元/万次，CPU 弹性实例按 vCPU 与内存执行时长计费，公网出流量为 0.8 元/GiB。本次 Beta 首发建议使用弹性实例、最小实例数 0，先不创建长期占用的预留实例；实际费用以控制台账单为准。

官方依据：

- 《计费概述》（更新于 2025-03-21）：https://www.volcengine.com/docs/6662/107454
- 《按量计费》（更新于 2025-08-27）：https://www.volcengine.com/docs/6662/1269135

## 9. 发布与回滚方案

1. 部署后端应用，配置生产环境变量。
2. 访问 `/api/v1/health`，要求 `status=ok`、`model_connected=true`。
3. 部署前端应用，将 `BACKEND_API_URL` 指向后端。
4. 验证错码拒绝、正码登录、对话、刷题、错题、校长工单、手机布局。
5. 对比 A/B 两个学员会话，确认数据不串号。
6. 记录前后端 Application ID、Function ID、发布记录和公网域名。
7. 上线异常时回滚到上一个已验收 Revision；不删除共享网关。

## 10. Beta 验收标准

- 公网 HTTPS 首页可打开，手机无横向滚动。
- 邀请码登录成功，Cookie 不可被前端 JavaScript 读取。
- 普通对话、学车压力疏导、政策/流程问答和科目一理论题可完成一轮。
- 输入超过 300 字时，前端阻止继续输入，绕过前端的 API 请求返回 422。
- 刷题、模拟考、错题和收藏可用；否定句“不想刷题”不自动跳转。
- 开放问题无可靠来源时不猜，以轻量补充提示代替 404 式错误卡。
- 服务错误不向用户展示 Python/Next.js 堆栈。

## 11. 暂不可宣称的能力

- 不可宣称“数据永久不丢”，直到 TOS 备份/恢复完成。
- 不可宣称“OCR 图片长期保存”，直到 TOS 接入。
- 不可宣称“全国政策实时更新”，当前仅能依据已入库权威资料回答。
- 不可宣称“已通过大并发压力测”，当前仅有工具和小规模冒烟能力。
