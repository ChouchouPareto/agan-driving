# 阿甘学车 V2.2 Beta.2 PE 与 Skill 修复验收报告

本次修复覆盖意图误判、聊天与讲题上下文断裂、技能缺少实际数据读写入口、口诀串题、政策生成失控，以及旧数据库导致的 RAG 检索错误。代码版本为 `2.2.0-beta.2`，提示词版本为 `pe-v1.4-context-tools`，分支为 `codex/v2.2-pe-skill-fixes-20261017`。

结论：已具备继续受控试点的工程条件，本次 42 轮真实模型场景的意图与动作路由均符合预期；这不是 100% 回答准确率或 RAG 召回率。语气仍有重复和泛化，政策时效、独立准确性评测与生产部署仍须另行验收。

## 1. 修复内容

| 问题 | 修复 | 验证 |
|---|---|---|
| “不想刷题”“别打开错题本”触发导航 | 否定意图优先，明确想练才显示确认入口 | 单元测试、真实模型、桌面与手机端 |
| “为什么”永远继承上一道题 | 统一聊天和讲题历史，区分题目上下文与情绪对话 | 跨话题、短追问、重新指代旧题 |
| C2/杭州/周末学习信息丢失 | 当前会话事实覆盖默认车型和地区 | 连续 4 轮拿证周期对话 |
| 口诀被自由生成或串题 | 已编排口诀独立输出，优先当前知识点 | 路口→酒驾切换、不调用生成模型 |
| 进度技能只说“看不到” | 查询所属学员在激活题库的答题次数、正确次数、薄弱知识点 | 真实数据库写入练习后读取统计 |
| 人工入口只存在于回复中 | 新增确认提交接口、前端按钮、归属校验、未关闭工单复用 | 不点击不创建，点击后可查看工单 |
| 刷新后普通聊天丢失 | 返回并恢复 AgentTurn，与题目按时间合并 | 桌面与 Pixel 5 浏览器场景 |
| 政策数字、界面能力被编造 | 资料事实与模型口语分离；每条摘要对应来源；校验失败降级 | 无依据数字、虚构考位界面被拦截 |
| 普通材料问题被误当隐私泄露 | 区分“要带身份证吗”与真实号码/证件上传语句 | 安全问法可答，敏感号码不进模型 |
| 旧 SQLite 缺少 embedding 列 | 启动时先备份再迁移，补充可续跑回填脚本 | 旧库迁移与幂等测试 |
| 开放问法得到“正确” | 非精确检索先排除不适配的判断题候选 | 混合题型回归、真实 embedding+rerank 链路 |

普通交流仍由模型结合上下文生成，不替换成一组随机模板。确定性输出只用于敏感/注入拦截、可信事实、已编排口诀和必要故障降级；这能避免为了自然表达而重写答案或法规数字。

## 2. 测试结果与口径

| 验证项 | 结果 | 范围 |
|---|---|---|
| 后端自动化 | 73/73 通过 | 含新增意图、上下文、技能、工单、迁移及 RAG 回归 |
| 前端单元测试 | 9/9 通过 | Vitest |
| 浏览器端到端 | 12/12 通过 | 桌面 Chromium + Pixel 5；使用测试后端和模拟 AI |
| 工程检查 | 全部通过 | TypeScript、ESLint、Next.js 生产构建 |
| 原有主场景真实模型复测 | 32/32 路由通过 | 优化前同组为 24/32 |
| 扩展真实模型复测 | 10/10 路由通过 | 替换问法、工具、口诀切换、非精确检索 |
| HTTP 与流式回答 | 42/42 HTTP 200；6/6 讲题流正常完成 | 本地应用 + 真实模型 + 临时数据库副本 |
| 受控降级 | 2 次 | 两条政策回复生成文本未通过校验，保留来源事实，不编造新结论 |

42 轮共记录 44 次模型请求，供应商均返回 HTTP 200；供应商报告的累计用量为 **48,196 tokens**（包含分类、重试、生成、embedding 和 rerank）。它不是本次全部开发测试的总费用或总用量。

本轮接口到完整回复的 P50 为 **2.715 秒**，P95 为 **5.506 秒**，最大 **5.620 秒**。按 42 条时长排序、nearest-rank 计算 P95；不是并发压测或首字延迟。主场景与扩展脚本可能同时执行，不代表生产负载。

真实模型使用本地私有配置：普通回复/分类 `qwen3.6-flash`，情绪与政策生成 `qwen3.7-plus`，向量 `text-embedding-v4`，重排 `qwen3-rerank`。生产模型以部署环境实际配置为准。

扩展用例参与了修复过程，不是独立盲测集；不能将其统计外推为全量准确率。原有激活题库补测与主场景合计 28/37 的历史路由结果，也不可直接与本次不同样本的 42/42 当作同口径提升。

## 3. 关键实测片段

- 输入“别跳转收藏页，先听我说”：回复“好，我不跳。你接着说。”，不提供导航动作。
- 路口题之后问“给个酒驾的口诀，不是刚才路口那题”：返回“喝酒不开车，开车不喝酒”，不再沿用路口口诀。
- 输入“机动车在没有红绿灯的交叉路口，应当怎样通过？”：调用真实向量与重排服务后返回“A. 减速慢行”，不再把相似判断题的“正确”当作回答。
- 输入“最近学时有什么新规定？”：说明仅检索到历史资料，提供对应来源，不声称已确认最新当地政策。
- 输入“我的正确率和薄弱点是什么？”：无记录时如实说明暂无记录；有记录的数据库回归用例验证实际答题次数与正确数。

## 4. 数据库与上线衔接

本地数据库已完成迁移；激活版本 `research-c1-text-preview-20260828` 已回填 **1,388 条、1,024 维**向量。迁移备份位于被 Git 忽略的 `data/backups/`，学员数据、私有题库、邀请码和模型密钥不上传仓库。

生产环境本次未部署，不能认为已有体验链接已升级。后续部署顺序：备份生产库 → 发布代码并完成迁移 → 使用该知识版本对应的模型/维度回填缺失向量 → 检查 readiness → 小流量验证聊天、真实题库和人工工单。

回填命令（在 backend 目录、有私有模型配置时运行）：

```sh
PYTHONPATH=. .venv/bin/python scripts/backfill_embeddings.py --workers 3
```

脚本仅处理激活版本缺失的向量，模型或维度不匹配时中止。调用模型会计费；不在每次应用启动时自动批量回填。

## 5. 仍需关注

- 自由生成仍偶有“这种感觉确实……”等重复措辞，学习进度回复可能重复统计后的解释；不能保证每一轮都像真人。
- 历史资料没有实时政策核验与当地考位接口，不提供固定拿证日期。
- 当前上下文是最近 8 轮，不是长期记忆；不会根据一句话永久改写档案。
- RAG 题型过滤、相似度门槛不是语义等价证明；需要独立改写题、否定题、冲突题和无答案集，才能报告 Recall@K、误答率。
- 单实例 SQLite、现有内存限流、真实用户隔离与并发工单重复创建等生产能力，仍须纳入多实例和压力测试。
- 依赖测试产生 4 条非阻断弃用警告（Starlette/httpx 与 Alembic 配置），测试无失败。
