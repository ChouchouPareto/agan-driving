# Loom参考UI统一设计系统 v1.0

## 1. 设计方向

第一版产品的整体外形、UI风格和交互感受以Refero中Loom公开页面样例为主参考，统一为：

> 中性浅色工作台、紫色单一品牌强调、内容优先、细边框卡片、紧凑圆角、克制滑动动效。

这是一套“借鉴设计语言、不复制具体页面”的规范。Loom参考负责整体感觉，本项目的问答、学习记忆、校长服务和驾校数据仍按自身业务重新布局。

## 2. 设计原则

1. 内容优先：答案、题目和处理状态先于装饰；
2. 单一强调：主页面只使用一套紫色品牌强调；
3. 层级清晰：页面、面板、卡片、浮层依靠背景与边框区分；
4. 操作克制：每个区域只有一个视觉最强的主行动；
5. 状态可见：加载、等待、处理中、完成和失败都有明确反馈；
6. 桌面像工作台，移动端像轻量助手；
7. 趣味只在文案和微交互，不破坏答案可信度。

## 3. 色彩Token

| Token | 色值 | 使用规则 |
|---|---|---|
| `primary` | `#625DF5` | 主按钮、激活态、重点链接 |
| `primary-hover` | `#514BE8` | 主按钮悬停 |
| `primary-pressed` | `#453FD4` | 主按钮按下 |
| `primary-soft` | `#F0EFFF` | 选中项、轻提示、紫色标签背景 |
| `background` | `#F7F7F8` | 页面整体背景 |
| `surface` | `#FFFFFF` | 卡片、面板、弹窗 |
| `surface-subtle` | `#FAFAFB` | 次级内容区、表格头 |
| `text-primary` | `#1B1B1F` | 标题和正文 |
| `text-secondary` | `#666672` | 辅助说明 |
| `text-tertiary` | `#91919B` | 时间、占位和弱提示 |
| `border` | `#E5E5EA` | 卡片、输入框、分割线 |
| `border-strong` | `#D3D3DA` | 悬停或聚焦前的强调边界 |
| `success` | `#168A50` | 已看懂、已改善、处理完成 |
| `warning` | `#B86A00` | OCR校正、等待和需要注意 |
| `danger` | `#D93D4C` | 错误、P0和删除 |
| `overlay` | `rgba(15,15,20,.48)` | 弹窗、抽屉遮罩 |

规则：

- 紫色是唯一品牌主色，不再使用青绿作为第二主色；
- 状态色只用于语义反馈，不能变成页面装饰；
- 正文对比度至少4.5:1；
- 不使用大面积高饱和渐变，渐变只允许用于极小面积品牌氛围。

## 4. 字体

```text
英文/数字：Inter
中文：Noto Sans SC
系统回退：PingFang SC / Microsoft YaHei / system-ui / sans-serif
```

| 层级 | 移动端 | 桌面端 | 字重/行高 |
|---|---:|---:|---|
| 页面标题 | 22px | 24px | 650 / 1.3 |
| 一级模块 | 18px | 20px | 600 / 1.4 |
| 卡片标题 | 16px | 16px | 600 / 1.5 |
| 正文 | 16px | 15px | 400 / 1.6 |
| 辅助文字 | 14px | 13px | 400 / 1.5 |
| 标签 | 12px | 12px | 500 / 1.3 |

中文回答正文在移动端不得小于16px。

## 5. 圆角、边框、阴影与间距

- 基础间距：4px；常用8、12、16、20、24、32px；
- 页面边距：移动端16px，桌面内容区24—32px；
- 按钮圆角：8px；
- 输入框圆角：10px；
- 卡片圆角：12px；
- 弹窗/抽屉圆角：16px；
- Pill筛选项：999px；
- 默认边框：1px `border`；
- 卡片默认无明显阴影；
- 浮层阴影：`0 12px 32px rgba(20,20,30,.12)`；
- 聚焦环：2px `primary`＋2px白色间隔。

## 6. 图标与图片

- 使用Lucide或同类线性SVG图标；
- 常规图标20px，导航图标18—20px，描边1.75px；
- 不使用Emoji充当功能图标；
- 校长头像可以使用克制的圆形人物标识，但不能成为大面积卡通插图；
- 题目截图使用4:3或原比例容器，加载时预留高度，避免页面跳动。

## 7. 学员端导航与布局

### 移动端

- 顶部栏高56px：返回/驾校标识、页面标题、通知；
- 内容区单列；
- 底部4项导航：`问一问 / 学习 / 校长回复 / 我的`；
- 对话页隐藏常规底栏，改用底部固定输入组件；
- 触控区域不小于44×44px。

### 桌面端学员Web

- 使用居中的单列应用壳，最大宽度720px；
- 左侧可增加64px窄导航，但不做复杂三栏；
- 页面背景为`background`，核心内容为白色面板。

### 教练与运营后台

- 左侧导航宽232px；
- 顶部工具栏高64px；
- 主内容区最大宽度1440px；
- 列表与详情可以使用双栏，但右侧详情面板不超过480px；
- P0告警固定在内容区顶部，不依赖弹窗才能发现。

## 8. 核心组件

### 按钮

- Primary：紫底白字，仅用于当前区域主行动；
- Secondary：白底深色字＋灰边框；
- Tertiary：透明底＋深色字；
- Danger：默认白底红字，只有确认删除时使用红底白字；
- 加载时保留原按钮宽度并显示16px旋转指示。

### 输入框

- 默认高44px，拍照问答输入区可扩展至56px；
- Focus使用紫色边框和聚焦环；
- 错误说明紧邻输入框下方；
- 不使用仅有placeholder而没有可见标签的复杂表单。

### Tab与筛选

- 主Tab使用文字＋底部2px紫色指示；
- 局部筛选使用浅灰Pill，选中后为`primary-soft`＋紫色文字；
- 切换只更新对应内容，不让整个页面闪烁重载。

### 卡片

- 白底、1px边框、12px圆角；
- 卡片内边距16px；
- 悬停只改变边框和极轻阴影；
- 回答卡通过左侧3px紫色强调线区分，不使用大块紫底。

### 弹窗、抽屉与底部面板

- 桌面设置和详情优先使用右侧抽屉；
- 移动端使用底部面板；
- 高风险确认使用居中弹窗；
- 打开时锁定背景滚动；
- 关闭后焦点返回触发按钮。

## 9. 滑动与动效统一参数

| 交互 | 动画 | 时长 | 缓动 |
|---|---|---:|---|
| 右侧抽屉 | 从右侧平移＋淡入 | 240ms | `cubic-bezier(.2,.8,.2,1)` |
| 移动端底部面板 | 自下向上＋遮罩淡入 | 260ms | `cubic-bezier(.2,.8,.2,1)` |
| Tab切换 | 指示条滑动＋内容淡入 | 160ms | `ease-out` |
| 开关Toggle | 滑块位移＋底色变化 | 180ms | `ease-out` |
| 卡片展开 | 内容淡入＋轻微下移 | 200ms | `ease-out` |
| Toast | 右上/顶部滑入 | 200ms | `ease-out` |
| 页面切换 | 透明度0→1，Y轴4px→0 | 180ms | `ease-out` |
| 骨架屏 | 低对比亮度流动 | 1200ms循环 | `linear` |

约束：

- 不用大幅弹跳、翻转和3D旋转；
- 不同时动画超过3个大区域；
- `prefers-reduced-motion`时关闭位移与循环动画；
- 抽屉和底部面板支持手势关闭时，必须有明确拖动柄和关闭按钮；
- 不依赖横向滑动作为唯一操作方式。

## 10. 页面规范

### 10.1 首页

```text
顶部栏：驾校名称 / 通知
标题：今天有什么没看懂？
主输入：输入题目或问题
操作：拍照提问（Primary）/ 文字提问（Secondary）
校长回复：未读工单卡
学习区：薄弱点、最近问题
```

首页首屏直接提问，不展示轮播Banner和营销宫格。

### 10.2 回答页

- 学员问题使用浅灰气泡；
- 直接答案进入白色重点卡，左侧紫色强调线；
- 一句话解释常显；
- 详细解释、易错点和法规依据通过Accordion逐项展开；
- 底部固定输入栏支持继续追问和拍照；
- “答案有问题”是次级文字按钮，避免误触。

### 10.3 OCR校正

- 桌面使用右侧抽屉，移动端使用底部面板；
- 上方显示原图，下方逐字段显示题干和选项；
- 低置信字段以浅橙边框标记；
- 修改后使用紫色“确认并提问”按钮；
- 不能识别时提供重新拍照和文字输入。

### 10.4 不懂就问校长

状态：

```text
提交给校长
→ 校长在摸鱼
→ 校长处理中
→ 校长已回复
→ 校长说好了
```

- 状态卡使用白底、紫色进度点和细线时间轴；
- “校长在摸鱼”使用小头像或轻微摆动，不使用大卡通动画；
- 同时展示正式说明：问题已进入队列，工作时间内预计2小时处理；
- 回复内容与原问题、依据和更新时间分区展示。

### 10.5 学习页

- 顶部使用分段Tab：薄弱 / 疑似薄弱 / 已改善；
- 知识点以列表卡呈现，不使用游戏化排行榜；
- 卡片可以向左轻滑显示“稍后复习”，但同时提供可见菜单按钮；
- 点击卡片从右侧/底部打开问题记录，而非跳到完全不同布局。

### 10.6 提醒与我的

- 提醒按今天/更早分组；
- 未读使用紫色小圆点，不使用整卡高饱和底色；
- 设置开关采用标准Toggle；
- 数据删除放在页面底部危险操作区，需要二次确认。

### 10.7 驾校后台

- 左侧导航：总览、校长工单、题库、知识库、评测、设置；
- 总览使用4张核心指标卡＋趋势图＋高频问题列表；
- 工单列表与右侧详情联动；
- 设置使用分组表单和Toggle，保存成功使用Toast；
- 密集表格保持44px最小行高并支持固定表头。

## 11. 响应式

| 宽度 | 规则 |
|---|---|
| `<768px` | 单列、底部导航、底部面板、固定输入栏 |
| `768—1199px` | 居中内容＋可折叠窄侧栏 |
| `≥1200px` | 完整侧栏、内容区、可选右侧详情抽屉 |

必须验证375px、768px、1024px和1440px；禁止横向页面滚动。

## 12. 可访问性与反馈

- 所有图标按钮必须有文字提示或`aria-label`；
- 键盘焦点清晰可见；
- 浏览器返回行为可预测；
- 状态变化通过`aria-live`适度播报；
- 网络、OCR、RAG和模型失败提供明确原因与下一步；
- 删除、退出和关闭提醒不能只靠颜色区分。

## 13. 禁止项

- 不再使用青绿色作为品牌主色；
- 不使用儿童教育风、黏土风和Comic字体；
- 不复制Loom Logo、商标、原插图和具体页面；
- 不使用厚阴影、重渐变和拟物按钮；
- 不展示模型置信度百分比给学员；
- 不把趣味状态用于P0、隐私或删除等严肃场景；
- 不让横向滑动成为唯一入口；
- 不在首页第一屏展示驾校营销广告。

## 14. 后续生成规则

后续任何线框图、高保真UI、前端页面或图片生成必须：

1. 先读取本设计系统；
2. 使用本文件的色彩、字体、圆角、间距和动效Token；
3. 页面结构以本PRD功能与状态为准；
4. 新增组件先进入组件表，不在单页自行发明风格；
5. 学员端和后台保持同一套品牌Token；
6. 若要改变主色、导航骨架或组件形态，必须先更新本设计系统再生成页面。
