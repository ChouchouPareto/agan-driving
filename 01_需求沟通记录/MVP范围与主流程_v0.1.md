# MVP范围与主流程 v0.1

## MVP目标

通过自有Web端，让真实科目一学员提出问题，AI基于RAG知识库输出正确答案、通俗解析与知识依据，并通过机器评测、教练审核和学员反馈形成持续纠错闭环。

MVP不作为公开通用刷题网站运营，而是通过试点驾校或教练邀请学员参与，模拟未来“驾校交付AI服务给学员”的真实关系。

## 本期核心角色

1. 学员：提出科目一问题、查看回答、反馈是否正确或是否解决。
2. 教练/专业审核员：审核机器标记或抽检的回答，纠正错误内容。
3. 运营/产品测试人员：维护测试账号、观察日志、管理评测结果。

## P0范围

### 学员Web端

- 由试点驾校或教练发放测试账号/邀请码；
- 必要的数据使用说明；
- 文字输入科目一问题；
- 展示正确答案、通俗解析和知识依据；
- 对答案进行正确、错误或未解决反馈；
- 查看必要的历史问答。

### AI服务

- 科目一问题识别；
- RAG知识检索；
- 固定结构回答；
- 无依据、低置信度和知识冲突处理；
- 回答日志与版本记录。

### 评测与审核

- 标准答案自动比对；
- 回答结构与依据一致性检查；
- 异常预警触发人工或教练审核；
- 错误分类、修改与重新评测；
- 学员错误反馈进入人工审核队列。

## 暂不进入MVP

- 科目二、科目三和科目四；
- 题目截图与OCR；
- 完整学习计划和主动推送；
- 情绪陪伴；
- 驾校小程序接入；
- 完整驾校管理系统；
- 多驾校租户、商业计费和复杂权限。

## 主流程

> 试点驾校/教练邀请真实学员 → 学员进入Web → 输入科目一问题 → 系统匹配题库/规则库 → 确定性返回标准答案 → 大模型生成通俗解释 → 机器执行自动检查 → 展示给学员 → 学员反馈 → 只有异常预警进入人工/教练审核 → 错误修正并沉淀到知识库和评测集 → 驾校获得试点效果反馈。

## 核心质量指标

回答正确率是MVP阶段的核心质量指标和上线门槛。标准化命中由机器评测，异常预警由真人教练或专业审核员复核。具体指标口径和门槛在方案评审阶段确定。
